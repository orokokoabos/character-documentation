# character-documentation

This documentation is mostly to document the character Francesca Badu. Everything included in the documentation that isn't Francesca, exists because it helps explain / gives conetxt when we talk about Francesca. For example there are many organizations, nations, and etc in /world-powers. However they only are documented because they can provide context to later when we want to talk / discuss Francesca. There are dozens and dozen of world powers that are not documented and do not exist in /world-powers, they exist in the story, however because they may not directly be relevant / relevant enough as context for us to discuss Francesca, we just haven't included them, so yes, there is a lot missing from the world building, this repo is incomplete, because we only care about things relevant to helping us discuss Francesca, if it's not relevant, we just havenn't included it in the repo. For example there is an organization called Hunting's Kitchen that is a world wide economic power in the series, however it is not relevant as context in any way when it comes to discussing Francesca, so we haven't included it in /world-powers so you don't know it exists, but it does, so many things are left out of this repo, do not assume this repo is the entire series, it's not.
