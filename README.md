## How to interpret this repository:

This repository is a Francesca Badu-focused reference, not a complete guide to the series. Its purpose is to state established facts about Francesca and provide the context needed to understand her. It documents only the other characters, events, and worldbuilding that serve that purpose.
Omissions are intentional. The series contains many arcs, protagonists, characters, and events that are not documented here because they do not help explain Francesca. An arc summary may cover only the Francesca-relevant events and necessary context; it is not a summary of the complete arc. 
This repository is a straightforward reference to what happens and what is established. It is not the story itself, a scene-by-scene retelling, or a substitute for the full narrative. Read descriptions as factual notes about the fictional canon, not as prose written to create suspense or reveal information gradually.
Francesca is intentionally unbeatable. She is designed to be an untouchable character who cannot lose. Her being the strongest is a defining premise, not a problem the story is meant to correct. shes not supposed to have weaknesses, that's the point.
